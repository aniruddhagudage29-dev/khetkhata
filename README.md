# 🌾 KhetKhata – Farm Expense & Profit Tracker

KhetKhata is a simple, multilingual, offline-first farming application designed to help small-scale farmers manage their agricultural expenses, record income, and track crop-wise profits and losses.

## ✨ Features

- 🌐 **Multilingual Support:** Marathi, Hindi, and English.
- 🌱 **Crop Tracking:** Onion, soybean, cotton, sugarcane, tur, and other crops.
- 💰 **Expense Management:** Record and categorize farming expenses.
- 📈 **Income Tracking:** Record crop-related income and calculate profits or losses.
- 📵 **Offline Support:** Designed to work without a continuous internet connection.
- 🗣️ **Voice Assistance:** Optional voice input and audio feedback on supported devices.
- 💾 **Data Backup:** Export and restore records using JSON and CSV formats.
- 📱 **Simple Interface:** Large buttons, readable text, and easy navigation.
- 🔒 **Privacy-Focused:** Stores farm records locally on the device.

## 🎯 Problem Statement

Small-scale farmers often rely on paper notebooks or memory to manage agricultural finances. Tracking expenses, income, and actual crop profits can be difficult, especially when internet access is limited or digital tools are not available in regional languages.

## 💡 Our Solution

KhetKhata provides a farmer-friendly digital ledger that simplifies financial record-keeping, helps farmers understand crop-wise profitability, and supports regional languages and offline usage.

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- Progressive Web App (PWA)
- Service Workers
- LocalStorage
- Web Speech API

## 👨‍🌾 Target Audience

- Small-scale farmers
- Farmers in rural and semi-urban areas
- Users who prefer Marathi or Hindi interfaces
- Farmers seeking a simple alternative to paper-based accounting

## 🚀 Getting Started

1. Open the application in a supported web browser.
2. Select your preferred language.
3. Choose a crop.
4. Enter farming expenses or income.
5. View the crop-wise financial summary.
6. Back up your records regularly.

## 🔮 Future Scope

- Additional Indian languages
- Seasonal profit and loss reports
- Improved regional-language voice recognition
- Optional cloud backup and synchronization
- Printable financial reports and advanced analytics

## 🔐 Privacy

Farm records are designed to remain on the user's device. Users should export backups regularly because clearing browser data or losing the device may result in data loss.

## 🏆 Project Goal

To make farm accounting simple, accessible, and understandable for small-scale farmers through an easy-to-use digital solution.
